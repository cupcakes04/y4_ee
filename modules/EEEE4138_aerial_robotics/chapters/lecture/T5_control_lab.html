The pattern in every loop: error → controller → acceleration request → mapping block → physical input → plant → integrators → feedback

outer / position controllerinner / attitude controllermapping (no dynamics: a formula)plant (physics, has dynamics)

The controller never outputs thrust or torque directly. It asks for an acceleration (u_z, u_x, α). A mapping block then converts it: T = m(g − u_z), θ_d = −u_x/g, M = Jα. Because of that, every loop's plant looks like 1/s² and uses the same gain rule k_p = ωn², k_d = 2ζωn. Signs: z is down (climb = negative), positive pitch is nose-up (forward = negative θ).

  2. PD: u_z = k_p e + k_d ė, with k_p = ωn², k_d = 2ζωn (from ë + k_d ė + k_p e = 0 ↔ s² + 2ζωn s + ωn²).
  3. Thrust map: T_cmd = m(g − u_z). Say the direction: u_z < 0 → up → T > mg.
  4. Plant + 1/s + 1/s: z̈ = g − T/m (+ d) → ż → z. Stability extras: e_ss = −d/k_p; with ∫, k_i < k_d k_p; with the motor, k_d > τ k_p.

2 · Cascade (T5-II sl.6, 14 = your Lab 3 model): x_d → θ_d → M_y → rotor thrusts → x

Row 1 is the outer loop. Its output wire θ_d is the reference for row 2, the inner loop. The inner loop's output M_y goes through allocation to the rotors (a + layout: 1 front, 3 rear, l = 0.25 m added). The plant then closes both loops: θ and q feed back to the inner Σ, and x and ẋ feed back to the outer Σ.

Predict first: on preset sl.17–19 (target 2 cm ahead), give the sign of every wire: e_x, u_x, θ_d, e_θ, α, M_y. Then which rotor speeds up, front (T₁) or rear (T₃)? Then press "inner too slow" and simulate.
checke_x +, u_x + (accelerate forward), θ_d − (nose down, sl.10), e_θ −, α −, M_y − (nose-down moment). M_y = l(T₁ − T₃) < 0 → rear T₃ goes up and front T₁ goes down. Lab 3 guide: "rear rotors speed up first". With the inner loop as slow as the outer, θ can't follow θ_d, so the outer loop is driving a slower plant than it was designed for: big overshoot and ringing (sl.16, Tut 5 Q1c).
Answer shape (T5-II sl.18–19, Tut 5 Q2): follow the wires left to right.
  1. Outer Σ: e_x = x_d − x, ė_x = −ẋ. Outer PD: u_x = ẍ_d + k_p e_x + k_d ė_x [m/s²].
  2. Tilt map: θ_d = −u_x/g [rad, then °]. u_x > 0 → nose down (thrust tilts toward +x).
  3. Inner Σ: e_θ = θ_d − θ. Inner PD: α = k_θ e_θ − k_dθ q [rad/s²]. ×J: M_y = Jα [N m] (or use K = Jk_θ, K_d = Jk_dθ).
  4. Say why: tilt is the only way to push sideways, and the inner loop must be faster (e.g. 25 vs 4 rad/s) because the outer loop assumes θ ≈ θ_d.

The 12-state model is the panel 2 diagram with every integrator drawn out (sl.48–49)

    
Inputs δT, δM_x, δM_y, δM_z. The chain is moments → (÷J, 1/s) → rates p q r → (1/s) → attitude → (×g, tilts thrust) → velocity → (1/s) → position. Every 1/s output is a state: 3 + 3 + 3 + 3 = 12.
