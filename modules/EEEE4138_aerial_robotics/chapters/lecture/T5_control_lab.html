T5 lab: asking for acceleration, then turning it into thrust and moments

Panel 1 is T5-I (vertical PD, offset, integral, motor lag). Panel 2 is T5-II part 1, the cascade your Lab 3 PositionPD → AttitudePD blocks implement. Panel 3 is T5-II part 2 (state space, controllability, pole placement): CW Task 3.

Source: EEEE4138 T5-I, T5-II (printed slide numbers), Tutorial 4 (= T5-I) and Tutorial 5 (= T5-II) solutions, Lab 3 guide. Not from these: added.

The one idea: every controller here asks for an acceleration. A separate line turns that into the physical input.

position error e = z_d − z→ PD →u (m/s²) → vertical: T_cmd = m(g − u_z) (÷ cosφ cosθ when tilted) · horizontal: θ_d = −u_x/g → attitude PD → α (rad/s²)→ M = J α →allocation (T4)→ Ωᵢ →aircraft (T3)

Because the request is an acceleration, the plant the PD sees is always the same double integrator 1/s²: z̈ = u_z (T5-I sl.14), ẍ ≈ −gθ (T5-II sl.9), θ̈ = M/J (T5-I sl.12). The same gain rule k_p = ωn², k_d = 2ζωn works for all three. Signs: z is down, so a climb has negative z and negative u_z. Positive pitch is nose-up, so forward needs negative θ.

Predict first: with the input δT, B = [0; −1/m] has a zero in the position row. Does that make position uncontrollable (Tut 5 Q3b)?
      
checkNo. Controllability is the rank of [B AB], not the entries of B. AB = [−1/m; 0] puts the input into position through velocity (one integration later), so [B AB] has rank 2.

    
Answer shape: "write A, B, C, D, test rank, place poles" (sl.30–44, Tut 5 Q3–Q4)
      
    
        
  1. State order x = [δz, w]. Write the equations as rows: δż = w, ẇ = (input). Read A, B off them. C = [1 0] for position output, D = 0.
    2. 
        
  2. B depends on the input units: v_c → [0; 1], δT → [0; −1/m]. A is unchanged.
    3. 
        
  3. Controllability [B AB], observability [C; CA]. Full rank (2) → reachable / inferable. Say it in words.
    4.

Hover links from the slides: θ̈ = M_y/J_y (T5-I sl.12) and ẍ ≈ −gθ (T5-II sl.9). So the pitch channel is a chain of four integrators, x ← u ← θ ← q ← M_y. The cascade (panel 2) controls it as two double-integrator loops, and state feedback can control it as one (sl.50). Writing the full 12 × 12 A and 12 × 4 B, and the rank test with outputs [p_N, p_E, p_D, ψ], is CW Task 3, so it's yours to derive.
