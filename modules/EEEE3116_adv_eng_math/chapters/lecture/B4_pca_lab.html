Set θ = 0 (skip the rotation), then go to 5 whiten. Is S = I?
check

No. The diagonal is 1, but the off-diagonal is ρ = 0.997. Dividing by σ only rescales; it can't remove covariance. Only rotating onto the PCs does that, which is why whitening comes after PCA.

Tick z-score, then snap. Where does PC1 point now? added
check

45°. z-scoring makes S = [1 ρ; ρ 1], and any such matrix has its PCs at 45°, with λ = 1 ± ρ = 1.997, 0.003. So z-scoring changes the PCs, but ÷N vs ÷(N−1) doesn't (that only scales every λ by the same factor).
