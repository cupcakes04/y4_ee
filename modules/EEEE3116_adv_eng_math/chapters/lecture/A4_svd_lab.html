A = Q σ Pᵀ says any matrix acts in three moves. Pᵀ reads the input x in the P axes. σ scales each amount. Q rebuilds the result along the Q axes. Eigen (A3) is the special case where both sets of axes are the same.

4 · Why the hand recipe works (the practical’s A)

The hand recipe is: AAᵀ → σ = √k → q → p = Aᵀq/σ → the leftover p from Ap = 0. Each step comes from one of three facts. Try each question on paper first, then reveal it. The checks use the practical’s A = [[2, 0, 1], [−1, 2, 9]] and the same Q, σ, Pᵀ as panel 2.

Fact 1 · How are P and Q linked?
Start from A = Q σ Pᵀ and multiply both sides on the right by P. Read the result one column at a time.
AP = Q σ (PᵀP) = Q σ ← PᵀP = I
column i: A pᵢ = σᵢ qᵢ
mirror (transpose first): Aᵀ qᵢ = σᵢ pᵢ

Input axis pᵢ lands on output axis qᵢ, stretched by σᵢ. In A3 an eigen axis lands on itself (Axᵢ = kᵢxᵢ). SVD lets it land somewhere else, but keeps the landing spots perpendicular. That is panel 1’s x / x⊥ sweep. The mirror form gives the recipe’s p = Aᵀq/σ.

Fact 2 · Why eig(AᵀA) gives P and σ²
Write AᵀA using A = Q σ Pᵀ. Which A3 form does it match?
AᵀA = (P σᵀ Qᵀ)(Q σ Pᵀ) = P (σᵀσ) Pᵀ ← QᵀQ = I
= X K Xᵀ with X = P, K = σᵀσ = diag(σ₀², σ₁², …)
AAᵀ = Q (σσᵀ) Qᵀ → Q = eigenvectors of AAᵀ

So an SVD is two A3 eigen problems: P from AᵀA, Q from AAᵀ, and σᵢ = √kᵢ. AᵀA is always symmetric, so A3’s perpendicular axes are guaranteed.

Fact 3 · Shapes (sl.15, full form), and why the recipe starts from AAᵀ
A is 2×3. Give the shapes of Q, σ, Pᵀ, AAᵀ and AᵀA. Which of AAᵀ and AᵀA is quicker to solve by hand?
A (N×M) = Q (N×N) · σ (N×M) · Pᵀ (M×M) practical: 2×3 = 2×2 · 2×3 · 3×3
AAᵀ is N×N = 2×2 → a quadratic. AᵀA is M×M = 3×3 → a cubic.

Both share the same nonzero eigenvalues, so the small one gives every σ. Then get P from pᵢ = Aᵀqᵢ/σᵢ without ever solving the 3×3. The 3×3 has one extra eigenvalue, 0. It belongs to p₂, the input axis with no σ partner (panel 2). added: start from the smaller product
