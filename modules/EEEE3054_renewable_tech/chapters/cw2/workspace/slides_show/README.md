## ⌨️ Presentation Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| **Right Arrow (`→`) / Space / PageDown** | Next slide |
| **Left Arrow (`←`) / PageUp / Backspace** | Previous slide |
| **`N` key / Click "📝 Speaker Notes"** | Toggle live Presenter Notes drawer (synced to current slide) |
| **`F` key** | Toggle browser fullscreen mode |
| **`Home` / `End`** | Jump to Slide 1 / Slide 10 |

## 🖨️ How to Export to PDF

1. Open [`index.html`](./index.html) in your browser.
2. Press **`Ctrl + P`** (or **`Cmd + P`** on Mac).
3. Set **Destination** to **"Save as PDF"**.
4. Set **Layout** to **Landscape**.
5. Set **Margins** to **None** (or Minimum).
6. Enable **"Background graphics"**.
7. Click **Save** $\rightarrow$ Saves perfectly as 10 clean 16:9 slides with no buttons, progress bars, or notes clutter.
