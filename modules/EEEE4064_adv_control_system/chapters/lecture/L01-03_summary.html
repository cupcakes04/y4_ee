The one idea behind all three lectures added
\[ G(s)=\frac{Y(s)}{U(s)}=\class{mC}{\mathbf C}\,(s\mathbf I-\class{mA}{\mathbf A})^{-1}\class{mB}{\mathbf B}+\class{mD}{D} \]

The denominator always lives in A; the companion and diagonal forms put the \(a_i\) or the poles there directly. The numerator gets split between B and C, and \(b_0\) (only nonzero when the numerator and denominator have equal degree) goes to D. Every form in L02 and L03 is one way of making that split. The formula is L03·s16; the "only B and D change" observation is L02·s21.

L01

Introduction: the state-space picture

  • State variables are the smallest set of variables that fix the state of the system L01·s10. They don't have to be measurable L02·s7.
  • An nth-order system gives n first-order equations, so A is n×n L02·s7.
  • Classical = TF, s-domain, SISO, root locus/Bode. Modern = state space, time domain, matrices, MIMO, pole placement, easy to program L01·s5–9.

L02

State-space representation: ODE → A, B, C, D

1

Write the ODE as \(y^{(n)}+a_1y^{(n-1)}+\dots+a_ny=\;\)right-hand side. For a physical system, derive this first, e.g. mass-spring-damper \(m\ddot y+b\dot y+ky=u\) L02·s8–9. Divide through so \(y^{(n)}\) has coefficient 1.

2

Does the right-hand side contain derivatives of u?

No: Case 1 L02·s13–14

\(x_1=y,\;x_2=\dot y,\dots,x_n=y^{(n-1)}\)

\(\class{mA}{\mathbf A}=\begin{bmatrix}0&1&&\\&\ddots&\ddots&\\&&0&1\\-a_n&\cdots&\cdots&-a_1\end{bmatrix}\)

\(\class{mB}{\mathbf B}=\begin{bmatrix}0\\\vdots\\0\\1\end{bmatrix},\;\class{mC}{\mathbf C}=[1\;0\cdots0],\;\class{mD}{D}=0\)

Yes: Case 2 L02·s15–17

Same A, same C. The u-derivatives get absorbed into the states (\(x_1=y-\beta_0u\), …), so they only show up in B and D:

\(\class{mB}{\mathbf B}=\begin{bmatrix}\beta_1\\\vdots\\\beta_n\end{bmatrix},\;\class{mD}{D}=\beta_0\)

\(\beta_0=b_0,\;\;\beta_k=b_k-a_1\beta_{k-1}-a_2\beta_{k-2}-\dots-a_k\beta_0\)

3

Check with Example 4 L02·s18–19: \(\dddot y+2\ddot y+3\dot y+4y=5\dddot u+6\ddot u+7\dot u+8u\) gives \(\beta=5,-4,0,0\), so \(\class{mB}{\mathbf B}=[-4\;0\;0]^T\), \(\class{mD}{D}=5\), and A has bottom row \([-4\;-3\;-2]\).

Watch the state ordering. Examples 1, 2 and 4 use \(x_1=y\). Example 3 L02·s10–11 numbers the states the other way round (\(x_1=\ddot y,\;x_3=y\)). The coefficient row then sits at the top of A, and \(\class{mB}{\mathbf B}=[6\;0\;0]^T\), \(\class{mC}{\mathbf C}=[0\;0\;1]\). Both are valid; it's the same chain read in the opposite direction.

Why Case 1 states aren't always used in practice: higher derivatives of a measured output are noisy L02·s13.

Can't rebuild: memorise

  • Companion A: 1s on the superdiagonal, bottom row \(-a_n\;\dots\;-a_1\) (reversed order) L02·s14
  • β recursion: \(\beta_k=b_k-\sum_{i=1}^{k}a_i\beta_{k-i}\), with \(\beta_0=b_0\) L02·s16
L03

Transformation of state space: one TF, many realisations

All four forms below are the same system, Example 1 L03·s11–12: \(G(s)=\dfrac{s+3}{s^2+3s+2}=\dfrac{2}{s+1}-\dfrac{1}{s+2}\). Look at which colour carries the numerator 3, 1 or the residues 2, −1.

CCF: controllableL03·s4, s11
\(\class{mA}{\begin{bmatrix}0&1\\-2&-3\end{bmatrix}}\;\class{mB}{\begin{bmatrix}0\\1\end{bmatrix}}\;\class{mC}{\begin{bmatrix}3&1\end{bmatrix}}\)
Numerator in C. A is the L02 companion. Used for controllability and pole placement.
OCF: observableL03·s6, s12
\(\class{mA}{\begin{bmatrix}0&-2\\1&-3\end{bmatrix}}\;\class{mB}{\begin{bmatrix}3\\1\end{bmatrix}}\;\class{mC}{\begin{bmatrix}0&1\end{bmatrix}}\)
CCF transposed: A→Aᵀ, B↔Cᵀ added. Numerator in B. Used for observability and simulation with initial conditions L03·s7.
DCF: diagonalL03·s8, s12
\(\class{mA}{\begin{bmatrix}-1&0\\0&-2\end{bmatrix}}\;\class{mB}{\begin{bmatrix}1\\1\end{bmatrix}}\;\class{mC}{\begin{bmatrix}2&-1\end{bmatrix}}\)
Poles on A's diagonal, residues in C. Only for distinct roots. Comes from partial fractions.
JCF: JordanL03·s9
\(\class{mA}{\begin{bmatrix}-p&1&0\\0&-p&1\\0&0&-p\end{bmatrix}}\;\class{mB}{\begin{bmatrix}0\\0\\1\end{bmatrix}}\;\class{mC}{\begin{bmatrix}c_1&c_2&c_3\end{bmatrix}}\)
For repeated roots. A triple pole gives one block with 1s above the diagonal, and \(G=\frac{c_1}{(s+p)^3}+\frac{c_2}{(s+p)^2}+\frac{c_3}{s+p}\). Example 1 has no repeated root, so this one is generic.
TF→SS

Write \(G=\frac{b_0s^n+\dots+b_n}{s^n+a_1s^{n-1}+\dots+a_n}\), then read off a form:

CCF: \(\class{mC}{\mathbf C}=[\,b_n-a_nb_0\;\;\cdots\;\;b_1-a_1b_0\,]\), \(\class{mD}{D}=b_0\) L03·s4. OCF: put that same list in B as a column L03·s6. DCF/JCF: factor the denominator, then use partial fractions L03·s8–9.

SS→TF

Laplace with \(\mathbf x(0)=0\): \((s\mathbf I-\class{mA}{\mathbf A})\mathbf X=\class{mB}{\mathbf B}U\), so \(G=\class{mC}{\mathbf C}(s\mathbf I-\class{mA}{\mathbf A})^{-1}\class{mB}{\mathbf B}+\class{mD}{D}\) L03·s14–16.

Example 2 L03·s17–18: upper-triangular A with diagonal −1, −1, −2 gives \(G=\frac{1}{(s+1)^2(s+2)}=\frac{1}{s^3+4s^2+5s+2}\). With C = [1 0 0] and B = e₃ you only need the top-right entry of the inverse.

L02 β-form vs L03 CCF added: same companion A, but the β-form puts the numerator into B (C = [1 0 … 0]), while CCF puts it into C (B = [0 … 0 1]ᵀ). If an answer has a different B and C from the official one, check which form was asked for before assuming it's wrong.

Slide wording to check: L03·s10 says Jordan is for "only multiple roots", but the s9 example mixes a triple root with distinct ones. In practice, each repeated root gets a Jordan block and the distinct roots stay diagonal. Ask the lecturer if this matters for the exam.

  • CCF's C runs backwards: \(b_n-a_nb_0\) first, \(b_1-a_1b_0\) last L03·s4
  • OCF = CCF transposed (A→Aᵀ, B↔Cᵀ). Remember one and you get the other added
  • \(G=\class{mC}{\mathbf C}(s\mathbf I-\class{mA}{\mathbf A})^{-1}\class{mB}{\mathbf B}+\class{mD}{D}\) L03·s16
