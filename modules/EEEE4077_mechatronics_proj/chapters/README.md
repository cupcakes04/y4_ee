# chapters — everything written

Engineering truth, sources and outward deliverables. Settled content only, except `notes/milestones/` (work in progress, promoted when done). Runnable code lives in [`ws/`](../ws/README.md).

| Path | Holds |
|---|---|
| [notes/brief.md](notes/brief.md) | **Read first.** Identity, spec + proposal commitments, supervisor guidance, the student, decision log |
| [notes/plan.md](notes/plan.md) | **Now / Next / Waiting**, milestones (dated, each ending in something runnable), parked debt |
| [notes/stack.md](notes/stack.md) | Tools per milestone + the student's depth map and *What clicked* |
| [notes/design.md](notes/design.md) | What we build: goal, assumptions, modules, interfaces, the comparison set |
| [notes/questions.md](notes/questions.md) | Open questions / risks (`Q#`), each with the test that settles it; closed ones point to their write-up |
| [notes/milestones/](notes/milestones/README.md) | Work in progress, one file per milestone, plus the `answer.md` inbox. Promoted when done |
| [notes/lessons/](notes/lessons/) | Learning notes for concepts as they come up (not assessed) |
| [research/](research/README.md) | Experiment write-ups, one per question (question → setup → results → verdict), with their logs and media. **Where measured numbers live** |
| [audits/](audits/) | Outside audit reports, one per audit ([AGENTS.md §5](../../../.agents/fyp/AGENTS.md#5-audits)) |
| [library/](library/README.md) | Sources: register, cards, PDFs, data-debt list. Only place a citation comes from |
| [deliverables/](deliverables/) | Outward outputs: `defense/`, `thesis/`, and `meetings/` (meeting records, user's) |

Session order: brief → plan → stack → the `status: active` milestone file.

Claim tags: `[L#]` library · `[M:<write-up>]` measured · `[E]` engineering judgement. Rules in [AGENTS.md §2](../../../.agents/fyp/AGENTS.md#2-claim-tags-applies-to-chapters-and-anything-derived-from-it).
