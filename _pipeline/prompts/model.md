# Gemini Prompt — Stage 3: Mental Model

> Run this AFTER all chapter notes for a subject are done (or after every few chapters).
> Paste the contents of all `notes/ch##_*.md` files, or upload them.
> Copy output into `models/subject_model.md`.

---

## Prompt

```
I have completed verbose chapter notes for a final year MEng engineering module. 
I will paste all the chapter notes below.

Your job is to build a SUBJECT-LEVEL MENTAL MODEL — a map of how everything connects.

RULES:
1. Identify the 3–5 load-bearing concepts: the things that, if understood deeply, make everything else derivable. Explain WHY each is load-bearing.
2. Build a concept dependency graph: which concepts must be understood before which others. Text form is fine.
3. Write a core narrative: one paragraph explaining what this subject is actually about at the engineering level — not the academic description, the real engineering story.
4. Identify subject-level anti-patterns: recurring mistakes or misconceptions that span multiple chapters.
5. Identify the highest-payoff areas for exam/assessment performance based on the content structure.
6. Flag any cross-chapter gaps: places where one chapter assumes something another chapter doesn't fully explain.

OUTPUT FORMAT:

## The Core Narrative
## Load-Bearing Concepts
## Concept Dependency Graph
## Anti-Patterns (Subject Level)
## Assessment Attack Strategy
## Cross-Chapter Gaps

Chapter notes below:
[PASTE ALL chapter notes here]
```
